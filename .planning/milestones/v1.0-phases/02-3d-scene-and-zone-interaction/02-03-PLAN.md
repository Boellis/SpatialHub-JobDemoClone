**Part A: Create `src/components/habitat/CameraController.tsx`:**

A component that lives inside the Canvas and manages smooth camera transitions when a zone is selected or deselected.

Props:
```typescript
interface CameraControllerProps {
  selectedZoneId: string | null;
  onDeselect: () => void;
}
```

Implementation:
1. Use `useThree` to get `camera` and `controls` (OrbitControls ref — or access via `useThree().controls`)
2. Actually, better approach: get OrbitControls via a ref passed down. Use `useThree` for camera.
3. Alternative (simpler): Remove `<OrbitControls>` from HabitatView and put it inside this component so CameraController owns the controls ref directly.
4. **Recommended approach:** Use drei's `<OrbitControls>` with a ref, managed by CameraController. CameraController renders `<OrbitControls ref={controlsRef} makeDefault enableDamping dampingFactor={0.05} minDistance={8} maxDistance={60} maxPolarAngle={Math.PI / 2.1} />` internally.

Camera transition logic:
- Define overview position: `const OVERVIEW_POS = new THREE.Vector3(0, 25, 35)` and target `const OVERVIEW_TARGET = new THREE.Vector3(0, 0, 0)`
- When `selectedZoneId` changes (useEffect):
  - If selected: compute focus position as zone position offset for close orbit (e.g., `zonePos + Vector3(5, 8, 10)` to look down at the dome from close range)
    - Focus target = zone position (the dome center)
    - Focus camera position = zone position + offset `(5, 8, 10)` (close orbit, slightly above and to the side)
  - If deselected (null): transition back to OVERVIEW_POS/OVERVIEW_TARGET
- Smooth transition using `useFrame`:
  - Keep a `targetPos` and `targetLookAt` as refs (THREE.Vector3)
  - On each frame, lerp camera.position toward targetPos with factor ~0.04 (gives ~0.8-1.2s settle)
  - Also lerp OrbitControls.target toward targetLookAt with same factor
  - Call `controls.update()` after lerping
  - Stop lerping when distance < 0.01 (converged)
- Use an `isTransitioning` ref to prevent lerping from fighting with user drag during transition

**Escape key handler:**
- `useEffect` in CameraController: add `keydown` listener on `window` for Escape key -> call `onDeselect()`
- Clean up on unmount

**Background click deselect:**
- Add an invisible large plane (or use Canvas `onPointerMissed` prop on the parent component) to detect clicks on empty space -> call `onDeselect()`
- Recommended: Use `onPointerMissed` on the `<group>` wrapping all domes in HabitatStructure — fires when clicking on anything NOT a dome

**Part A: Create `src/components/habitat/SensorOrb.tsx`:**

A small glowing sphere inside a dome representing a single sensor, with live data tooltip on hover.

Props:
```typescript
interface SensorOrbProps {
  sensorId: string;
  zoneId: string;
  sensorName: string;
  unit: string;
  position: [number, number, number]; // relative to dome center
}
```

Implementation:
1. **Orb mesh:**
   - Small sphere: `<sphereGeometry args={[0.25, 16, 16]} />` (0.25 radius, enough segments for smooth look)
   - Material: `<meshStandardMaterial emissive={statusColor} emissiveIntensity={2.0} color={statusColor} transparent opacity={0.9} />`
   - Status color mapping: green='#00ff44', yellow='#ffaa00', red='#ff2200'

2. **Live data from store:**
   - `const reading = useHabitatStore(selectSensorReading(zoneId, sensorId));`
   - Color updates every 2s as the simulation ticks

3. **Subtle animation:**
   - Use `useFrame` to make the orb gently bob up and down: `meshRef.current.position.y = baseY + Math.sin(clock.elapsedTime * 1.5 + phaseOffset) * 0.1`
   - `phaseOffset` derived from sensorId hash so orbs don't bob in sync (e.g., `sensorId.charCodeAt(0) * 0.5`)

4. **Hover tooltip:**
   - Track hover: `const [hovered, setHovered] = useState(false)`
   - On hover, show drei `<Html>` positioned above the orb with:
     - Sensor name (e.g., "CO2 Level")
     - Current value formatted to 1 decimal place + unit (e.g., "812.3 ppm")
     - Status indicator dot
   - Style: dark background (#0a0a0aCC), padding 6px 10px, border-radius 4px, monospace font, font-size 11px, white text, pointer-events: none
   - `<Html center distanceFactor={8} style={{ pointerEvents: 'none' }}>`
   - Only render the Html component when hovered (conditional rendering) to avoid 12 always-present DOM overlays

5. **Pointer events:**
   - `onPointerOver` / `onPointerOut` for hover state
   - Orb clicks should NOT propagate to the dome click handler: `onClick={(e) => e.stopPropagation()}`

6. Named export: `export const SensorOrb`
