1. Create `src/components/habitat/` directory.

2. Create `src/components/habitat/MarsEnvironment.tsx`:
   - A React component rendered inside the R3F Canvas (uses R3F hooks, NOT HTML)
   - Ground plane: a large flat `<mesh>` (PlaneGeometry, ~200x200, rotated -PI/2 on X to be horizontal) with `<meshStandardMaterial>` using a rusty Mars color (e.g., #2a1510 or similar dark rust), roughness ~0.9, metalness ~0.1
   - Ambient light: intensity ~0.15 (very dim — mission control darkness)
   - Directional light: warm-ish orange-white (color ~#ffe0c0), intensity ~0.6, position [15, 20, 10], castShadow=true
   - Fog: use `<fog attach="fog" args={['#050505', 30, 80]} />` on the Canvas scene for atmosphere edge fade — dark blackish fog that hides the ground edges
   - No skybox — just the dark background color (Canvas gl.setClearColor or scene background)
   - Export as named export: `export const MarsEnvironment`

3. Create `src/pages/HabitatView.tsx`:
   - Full-screen Canvas taking 100vw x 100vh (use a wrapper div with `position: fixed; inset: 0; background: #0a0a0a`)
   - R3F `<Canvas>` with:
     - camera prop: `{{ position: [0, 25, 35], fov: 50 }}` — elevated overview looking down at the habitat area (zone positions range from x:-8..8, z:-4..4, so camera at ~35 units back and ~25 up gives a good overview)
     - gl prop: `{{ antialias: true, alpha: false }}` (opaque background, AA on)
     - `onCreated={({ gl }) => gl.setClearColor('#050505')}` — near-black sky
   - Inside Canvas: `<MarsEnvironment />`, `<OrbitControls>` from drei with:
     - `makeDefault` (so it's the default control scheme)
     - `enableDamping` dampingFactor={0.05}
     - `minDistance={8}` maxDistance={60} (prevent zooming through ground or losing the scene)
     - `maxPolarAngle={Math.PI / 2.1}` (prevent going below ground plane)
   - Export as default export (required for React.lazy dynamic import): `export default HabitatView`
   - Also export as named for consistency: `export { HabitatView }`
