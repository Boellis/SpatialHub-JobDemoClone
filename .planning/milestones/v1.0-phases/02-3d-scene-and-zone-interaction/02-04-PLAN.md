The root cause: the dome `<mesh>` (sphereGeometry radius 5, upper hemisphere) is a solid convex surface that encloses all sensor orbs. R3F raycasts hit the dome mesh first, the dome's `onPointerOver` calls `stopPropagation()`, and pointer events never reach the `SensorOrb` meshes inside.

The fix has two parts:

**Part A — Make the dome mesh invisible to raycasting:**
On the dome `<mesh>` element (the one with `ref={domeRef}`, `sphereGeometry`, and `meshStandardMaterial` for the dark metallic body), add the prop `raycast={() => {}}` (a no-op function). This tells R3F to skip this mesh during raycasting entirely. Raycasts will now pass through the dome geometry and hit the sensor orb meshes inside.

Remove the `onPointerOver`, `onPointerOut`, and `onClick` props from the dome mesh — it can no longer receive events anyway.

**Part B — Add a separate invisible interaction ring for dome hover/click:**
Add a new `<mesh>` element AFTER the dome mesh (but before the sensor orbs) that acts as the dome's click/hover target. This mesh should be a flat ring at the dome base that does NOT occlude the sensor orbs:

```tsx
{/* Invisible interaction ring — flat annulus at dome base for hover/click.
    Sits at y=0.01, ring from radius 3.5 to 5.5. Covers the dome rim area
    where users naturally hover/click, but does NOT block raycasts to sensor
    orbs which are above y=1.5 and inside radius ~3.5. */}
<mesh
  rotation={[-Math.PI / 2, 0, 0]}
  position={[0, 0.01, 0]}
  onPointerOver={handlePointerOver}
  onPointerOut={handlePointerOut}
  onClick={handleClick}
  visible={false}
>
  <ringGeometry args={[3.5, 5.5, 64]} />
  <meshBasicMaterial />
</mesh>
```

Key constraints:
- The `ringGeometry` inner radius (3.5) is chosen so it does NOT overlap sensor orb positions (max orb offset magnitude is ~3.5 but orbs are elevated at y=1.5-3.0, while the ring is at y=0.01 — no geometric intersection).
- `visible={false}` hides the mesh visually but R3F still raycasts against invisible meshes by default, so hover/click events fire normally.
- Preserve the existing `handlePointerOver`, `handlePointerOut`, and `handleClick` functions exactly as they are (including `stopPropagation` and cursor changes).
- Do NOT modify SensorOrb.tsx — it already works correctly once events reach it.
- The rim torus meshes (`rimRef`, `accentRef`) do NOT have event handlers and are purely visual, so they need no changes.
