Create `src/components/habitat/HabitatDome.tsx` — a single dome component that takes zone config and renders:

**Props interface:**
```typescript
interface HabitatDomeProps {
  zoneId: string;
  name: string;
  position: [number, number, number];
  accentColor: string; // hex color, e.g., '#00ff88'
}
```

**Dome geometry:**
- Use drei `<Sphere>` or raw `<mesh>` with `<sphereGeometry args={[5, 32, 32, 0, Math.PI * 2, 0, Math.PI / 2]} />` — half-sphere (dome) with radius ~5 units, 32 segments for smooth look
- Position the dome so its flat base sits on y=0 (the ground plane) at the zone's x,z position
- Dome base material: dark metallic — `<meshStandardMaterial color="#1a1a2e" metalness={0.7} roughness={0.3} transparent opacity={0.85} />`

**Accent ring / rim glow:**
- Add a `<mesh>` ring at the dome base (TorusGeometry or RingGeometry) with emissive material using the accent color
- The emissive intensity drives the bloom effect — this is where the "glow" comes from
- Use `<meshStandardMaterial emissive={accentColor} emissiveIntensity={emissiveIntensity} color="#000" transparent opacity={0.9} />`

**Status-reactive emissive intensity:**
- Subscribe to zone status from Zustand: `const zone = useHabitatStore(selectZone(zoneId));`
- Map status to emissive intensity:
  - green: 1.5 (calm steady glow)
  - yellow: 3.0 (noticeably brighter)
  - red: pulsing between 2.0 and 5.0 (use `useFrame` with sine wave, ~2Hz: `2.0 + 3.0 * Math.abs(Math.sin(clock.elapsedTime * 4))`)
- For red status, also shift the emissive color toward red: lerp from accentColor toward '#ff2200'

**Accent color assignments (Claude's discretion):**
- grow-bays: '#00ff88' (green — plants, growth)
- atmosphere-control: '#00aaff' (blue — air, sky)
- water-recycling: '#8844ff' (purple — water processing)
- power-thermal: '#ff6600' (orange — energy, heat)

**Floating HTML label:**
- Use drei `<Html>` component positioned above the dome (~y=6 relative to dome center)
- `center` prop for horizontal centering, `distanceFactor={15}` for perspective scaling
- Content: zone name + a small colored dot/badge showing current status
- Style with inline CSS: dark semi-transparent background (#0a0a0a80), padding, border-radius, monospace font, color white, small font size
- Status badge: small circle div with background matching status color (green=#00ff44, yellow=#ffaa00, red=#ff2200)

**Named export:** `export const HabitatDome`

   - 4 corridors connecting adjacent domes (top-left to top-right, top-left to bottom-left, top-right to bottom-right, bottom-left to bottom-right — forming a square/rectangle)
   - Each corridor: `<mesh>` with CylinderGeometry (radius ~0.4, length = distance between dome edges), rotated and positioned to connect dome bases
   - Material: `<meshStandardMaterial color="#1a1a2e" transparent opacity={0.4} emissive="#334455" emissiveIntensity={0.5} />` — semi-transparent with subtle glow
   - Calculate corridor position as midpoint between two dome positions, rotation using Math.atan2 to aim at the target dome
   - Create a helper function `createCorridor(from: [x,y,z], to: [x,y,z])` that returns the position, rotation, and length

3. **Bloom post-processing:**
   - Import `EffectComposer` and `Bloom` from `@react-three/postprocessing`
   - Add after all scene geometry:
     ```tsx
     <EffectComposer>
       <Bloom
         luminanceThreshold={0.8}
         luminanceSmoothing={0.3}
         intensity={1.5}
         mipmapBlur
       />
     </EffectComposer>
     ```
   - The `luminanceThreshold` of 0.8 ensures only emissive elements (with intensity >1) bloom — the ground, dome base materials, and dim lights won't bloom

4. Named export: `export const HabitatStructure`
