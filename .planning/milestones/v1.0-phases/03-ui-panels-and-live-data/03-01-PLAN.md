<objective>
Lift zone selection state to Zustand, build the HTML overlay layer, and create the ZonePanel + Sparkline components that show live sensor readings when a dome is clicked.

Purpose: This is the foundational UI overlay work for Phase 3. The selectedZoneId must be shared between the R3F scene graph (which handles dome clicks and camera transitions) and the HTML overlay layer (which renders the detail panel). Without this state lift, the 3D and 2D layers cannot communicate. The ZonePanel and Sparkline are the primary data display — the "payoff" of clicking a dome.

Output: Working zone detail panel with live updating sensor readings and sparkline charts, full-screen immersive /habitat experience with hidden nav.
</objective>

**Panel header:**

- Zone name as title (text-lg, font-bold, text-white, font-mono)

**Sensor rows:**
- Iterate `config.sensors` and for each, get live reading: `zone.sensors[sensor.sensorId]`
- Each row shows:
  - Status dot: 8px circle, background = status color (green: #00ff44, yellow: #ffaa00, red: #ff2200), with subtle box-shadow glow
  - Sensor name: text-sm, text-gray-300, font-mono

  - Sparkline: `<Sparkline data={reading.history} color={statusColor} />`
- Value display precision per CONTEXT.md:
  - temperature: 1 decimal (`value.toFixed(1)`)
  - pH: 1 decimal
  - CO2, power, TDS: integer (`Math.round(value)`)
  - percentage types (humidity, O2, filtration, battery): 1 decimal
  - flow rate: 1 decimal
  - pressure: 1 decimal
  Create a helper function `formatSensorValue(value: number, type: string): string` that returns the correctly formatted string based on sensor type.

**Smooth number transition (~200ms):**
- Use a simple approach: CSS `transition: all 200ms ease-out` on the value text container with `font-variant-numeric: tabular-nums` for stable width. The value itself changes discretely every 2s, but with tabular-nums the digits don't jump horizontally.
- For actual smooth interpolation: use a tiny custom hook `useAnimatedValue(target: number, duration: number)` that lerps from previous to current over ~200ms using requestAnimationFrame. This makes the readout feel like a real instrument. Keep it simple — just linear interpolation over duration ms.

**Cross-fade on zone switch:**
