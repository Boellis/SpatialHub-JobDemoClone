**1. Create `src/components/habitat/AnomalyDrawer.tsx`:**

This component has three visual parts: (A) the always-visible toggle button, (B) the collapsible scenario drawer, and (C) scenario announcement banners.

**CSS Animation Injection (follow AlertBanner pattern):**
- Create `ensureAnimationsInjected()` with style id `anomaly-drawer-animations`
- Define keyframes:
  - `drawerSlideUp`: `from { transform: translateY(20px); opacity: 0 } to { transform: translateY(0); opacity: 1 }` -- 300ms ease-out
  - `scenarioBtnPulse`: `0%,100% { box-shadow: 0 0 6px rgba(255,34,0,0.3) } 50% { box-shadow: 0 0 14px rgba(255,34,0,0.7) }` -- 1.5s infinite
  - `announcementSlideDown`: `from { transform: translateY(-20px); opacity: 0 } to { transform: translateY(0); opacity: 1 }` -- 300ms ease-out
- Call in useEffect on mount.

**State:**
- `isOpen` local useState (starts `false` per user decision: drawer starts collapsed)
- Subscribe to store: `anomalies`, `scenarioAnnouncements`, `triggerAnomaly`, `dismissAnnouncement`
- Import `ANOMALY_SCENARIOS` from `../../simulation/anomalies`
- Import `ZONE_ACCENT_COLORS` from `./HabitatStructure`

**(A) Toggle Button:**
- Position: `fixed`, `bottom: '1.5rem'`, `left: '50%'`, `transform: 'translateX(-50%)'`
- `pointerEvents: 'auto'`
- Styling: glassmorphism (`rgba(10, 12, 18, 0.85)`, `blur(12px)`), border `1px solid rgba(255,255,255,0.1)`, borderRadius `20px`, padding `8px 18px`
- Content: small icon or text like a warning/hazard symbol plus "SCENARIOS" in monospace 11px, letterSpacing 0.1em, color rgba(255,255,255,0.5)
- On click: toggle `isOpen`
- If any anomaly is active (any entry in `anomalies` has phase !== 'idle'), show a small red dot indicator on the button

**(B) Scenario Drawer (rendered when `isOpen`):**
- Position: `fixed`, `bottom: '4rem'` (just above the toggle button), `left: '50%'`, `transform: 'translateX(-50%)'`
- `pointerEvents: 'auto'`
- animation: `drawerSlideUp 300ms ease-out`
- Glassmorphism styling matching HUD/ZonePanel
- Border: `1px solid rgba(255,255,255,0.08)`
- Padding: `12px 16px`
- Contains a close button (X) at top-right corner of drawer -- small, subtle, `onClick: () => setIsOpen(false)`
- Contains 4 scenario buttons in a horizontal row (`display: flex`, `gap: '10px'`)

**Each Scenario Button:**
- Determine if active: `anomalies[scenario.id]` exists and phase !== 'idle'
- onClick: call `triggerAnomaly(scenario.id)` -- the store action handles toggle logic (if already active, it cancels)
- Layout: vertical stack -- icon on top (fontSize 18px), label below (fontSize 11px, monospace, letterSpacing 0.06em)
- Inactive state: `background: 'transparent'`, `border: '1px solid rgba(255,255,255,0.15)'`, `color: 'rgba(255,255,255,0.5)'`
- Active state: `background: 'rgba(255,34,0,0.15)'`, `border: '1px solid #ff2200'`, `color: '#ff2200'`, `animation: 'scenarioBtnPulse 1.5s ease-in-out infinite'`
- borderRadius: `8px`, padding: `10px 14px`, cursor: `pointer`, transition on border/background for non-animated properties
- minWidth: `80px`, textAlign: `center`

**(C) Scenario Announcement Banners:**
- Render from `scenarioAnnouncements` array in store
- Position: `absolute`, `top: '0.5rem'` (ABOVE AlertBanner's `top: 1.5rem` to avoid collision), `left: '50%'`, `transform: 'translateX(-50%)'`
- pointerEvents: 'none' on container, 'auto' on each banner
- Each banner: glassmorphism, wider than regular alerts (`minWidth: '380px'`), borderLeft `4px solid ${ZONE_ACCENT_COLORS[announcement.zoneId]}` (zone accent color, NOT red)
- Content: `"WARNING: {LABEL} DETECTED -- {ZONE_NAME}"` in monospace, fontSize 13px, fontWeight 700, letterSpacing 0.08em, color white
- animation: `announcementSlideDown 300ms ease-out`
- Auto-dismiss: useEffect with setTimeout(8000ms) per announcement -- calls `dismissAnnouncement(announcement.timestamp)` on expiry. Clean up timeouts on unmount.
- Display flex column with 8px gap for multiple simultaneous announcements

- Add `<AnomalyDrawer />` inside the overlay div (the `pointerEvents: 'none'` fixed div), as a sibling to HabitatHUD, AlertBanner, and ZonePanel. Place it after AlertBanner and before the ZonePanel conditional.

HOWEVER, since AnomalyDrawer manages its own open/closed state internally and HabitatView doesn't know about it, the simplest approach is to REMOVE the hint text entirely.
