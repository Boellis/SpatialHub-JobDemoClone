## Scaffold Visual Contract

What renders on `/habitat` after Phase 17 is complete:

### Full-Viewport Container
```
position: fixed
inset: 0
background: #06070b  (--bg-void)
overflow: hidden
```

### R3F Canvas (background layer)
```
position: absolute
inset: 0
zIndex: 0
events: null         (CRITICAL — no raycaster)
gl.antialias: false  (no bloom, no EffectComposer)
gl.alpha: true
camera.position: [0, 0, 5]
camera.fov: 60
```
Canvas is empty in Phase 17. `ParallaxBackground` lands in Phase 20.

### DOM Grid Layer (foreground layer)
```
position: relative
zIndex: 1
width: 100%
height: 100%
```
Contains only the dev debug zone list in Phase 17. Phase 18 adds `PriorityGrid` here.

### Dev Debug Zone List (Phase 17 only — remove in Phase 18)
```
position: absolute
top: 24px   (--space-lg)
left: 24px  (--space-lg)
font-family: Space Mono, monospace
font-size: 13px
color: #e2e5ed
line-height: 1.6
pointer-events: none
```
Renders ranked zone IDs from `usePriorityRanking()` as a numbered list. Allows visual verification of hook output in browser without devtools. Example render:
```
1. water-recycling   [score: 23]
2. atmosphere-control [score: 10]
3. grow-bays          [score: 3]
4. power-thermal      [score: 0]
```
Position number in `#00aaff`. Zone ID and score in `#e2e5ed`.

## Suspense Loading State

The `TvDashboardView` lazy-loaded chunk triggers a Suspense fallback on initial load. Reuse the existing `.loading-spinner` + `.loading-text` classes from `index.css`.

```
Spinner: 32px × 32px
         border: 2px solid rgba(255,255,255,0.05)
         border-top-color: #00aaff (--accent-cyan)
         animation: spin 0.8s linear infinite

```

Source: existing `.loading-state` / `.loading-spinner` / `.loading-text` classes in `index.css` — no new CSS required.
