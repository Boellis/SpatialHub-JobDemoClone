**Title:** `# SpatialHub Mars Habitat Demo -- Competition Setup Guide`

**Section 1: Prerequisites**
- List what ships in the box: Raspberry Pi 4 (4GB+), Atlas Scientific pH EZO sensor, EZO carrier board or breadboard, jumper wires (SDA, SCL, VCC, GND), micro-USB pH probe, SD card (pre-flashed)
- List what the judge provides: WiFi network with internet access (no captive portals), USB-C power supply for Pi (5V/3A), monitor + HDMI cable (optional -- SSH works headless)
- State clearly: "The SD card ships pre-configured. You will only need to set your WiFi credentials."

**Section 2: Hardware Setup (~5 min)**

Sub-section 2.1 -- EZO I2C Mode Switch:
- Atlas EZO ships in UART mode by default. I2C mode requires a one-time physical configuration.
- Steps: (1) With power OFF, connect a jumper wire from the PGND pin to the TX pin on the EZO circuit. (2) Power on the Pi. (3) Wait for LED to change from green to blue (indicates I2C mode). (4) Remove the PGND-TX jumper. (5) Power cycle the Pi once more.
- Note: "This only needs to be done once. The EZO remembers its mode after power cycling."

Sub-section 2.2 -- Breadboard Wiring:
- Provide an ASCII wiring diagram showing these 4 connections between Pi GPIO header and Atlas EZO:
  ```
  Pi GPIO Pin 1  (3.3V)  --> EZO VCC
  Pi GPIO Pin 3  (SDA1)  --> EZO SDA
  Pi GPIO Pin 5  (SCL1)  --> EZO SCL
  Pi GPIO Pin 6  (GND)   --> EZO GND
  ```
- Note: "Connect the pH probe to the BNC connector on the EZO carrier board."

Sub-section 2.3 -- I2C Bus Configuration:
- Add to `/boot/firmware/config.txt`: `dtparam=i2c_arm=on,i2c_arm_baudrate=10000`
- Explain why: "The default 400 kHz baud rate causes sensor drop-off after 30-60 minutes. Setting 10 kHz ensures stable long-term operation."
- Reboot required after this change.

Sub-section 2.4 -- Verify Sensor Connection:
- Command: `i2cdetect -y 1`
- Expected output: address `63` (0x63 = 99 decimal, the default pH EZO address) should appear in the grid
- If nothing shows: "Go back to step 2.1 -- the EZO is likely still in UART mode."

**Section 3: Software Setup (~5 min)**

Sub-section 3.2 -- Configure WiFi:

Sub-section 3.5 -- Test Mode (Quick Check):

Sub-section 3.6 -- Auto-start on Boot:
- Create a systemd service at `/etc/systemd/system/hubclient.service`:
  ```ini

  Description=SpatialHub pH Sensor Client
  After=network-online.target
  Wants=network-online.target

  [Service]
  Type=simple
  User=pi
  WorkingDirectory=/home/pi/hubcode

  RestartSec=10

  ```

- Check status: `sudo systemctl status hubclient`
