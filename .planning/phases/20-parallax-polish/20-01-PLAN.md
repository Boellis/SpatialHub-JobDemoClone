    **Geometry strategy: InstancedMesh (Claude's discretion — GPU efficient for 80 identical spheres).**
    - Single shared SphereGeometry (6 segments — low-poly is invisible at radius 0.02-0.08)
    - Single shared MeshBasicMaterial with:
      - color: BASE_COLOR
      - transparent: true
      - opacity: 0.12 (midpoint of range — per-instance color variation handles the rest)
      - blending: THREE.AdditiveBlending (glow on dark bg per user decision)
      - depthWrite: false (prevents z-fighting with transparent particles)
    - InstancedMesh with count=PARTICLE_COUNT

    **Per-particle data (generated once in useMemo, NOT on every render):**
    - For each particle i (0 to PARTICLE_COUNT-1):
      - baseX: random in [-6, 6] (viewport spread for fov 60 at z=-2 to -8)
      - baseY: random in [-4, 4]
      - z: random in Z_RANGE
      - radius: random in RADIUS_RANGE
      - freqX: random in FREQ_RANGE
      - freqY: random in FREQ_RANGE (independent from freqX)
      - phaseX: random in [0, 2*PI]
      - phaseY: random in [0, 2*PI]
      - ampX: random in AMP_RANGE
      - ampY: random in AMP_RANGE
      - hueShift: random in [-HUE_VARIATION, +HUE_VARIATION]

    **Per-instance color via InstancedMesh.instanceColor:**
    - Use THREE.Color().setStyle(BASE_COLOR).offsetHSL(hueShift, 0, 0) per particle
    - Set instanceColor attribute on mount

    **Per-instance scale via matrix:**
    - Set initial transform matrix for each instance: position (baseX, baseY, z), scale (radius, radius, radius)

    **Animation via useFrame (not clock-based — useFrame is the established R3F pattern in this codebase):**
    - On each frame, for each particle:
      - x = baseX + sin(elapsedTime * freqX + phaseX) * ampX
      - y = baseY + sin(elapsedTime * freqY + phaseY) * ampY
      - z stays fixed (depth layer, per user decision)
      - Update instance matrix (position only, scale unchanged)
      - Set instanceMatrix.needsUpdate = true once after loop

    **GPU memory safety (Pitfall 3):**
    - Geometry and material created via useRef, NOT inline in JSX and NOT in useEffect
    - R3F JSX-declared geometries and materials get automatic disposal on unmount
    - Use declarative JSX pattern: `<instancedMesh><sphereGeometry /><meshBasicMaterial /></instancedMesh>`
    - This way R3F handles disposal — no manual .dispose() needed
