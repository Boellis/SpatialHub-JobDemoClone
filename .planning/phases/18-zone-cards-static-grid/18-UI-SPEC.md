> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none — custom CSS variables via `index.css` |
| Icon library | none — status dots are inline `<div>` elements |
| Font (display) | Rajdhani, sans-serif (`--font-display`) |
| Font (body) | Outfit, sans-serif (`--font-body`) |
| Font (mono / TV) | Space Mono, monospace (`--font-mono`) |

Source: `spatialhub-frontend/src/index.css` `:root` tokens + existing TV component inline style patterns.

All TV components (`StatusBar`, `ZoneCard`, `PriorityGrid`) use **inline styles only** — no CSS class names. This is the established pattern for all habitat and TV overlay components. Do not introduce Tailwind or CSS modules.

## Spacing Scale

Declared values match existing `--space-*` tokens (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-dot gaps, sensor row internal padding |
| sm | 8px | Sensor row vertical rhythm |
| md | 16px | Card inner padding (secondary cards), label spacing |
| lg | 24px | Card gap in grid (locked: `gap: 24px`) |
| xl | 32px | Grid padding from viewport edges (locked: `padding: 32px`) |
| 2xl | 48px | StatusBar height (locked: `height: 48px`) |

Exceptions:
- StatusBar horizontal padding: 32px (uses xl, not a new value)
- Status dot size: 8px (xs × 2 — acceptable inline sub-token)
- Card border radius: 10px (`--radius-md`) for secondary cards; 12px (`--radius-md` + 2) for hero card — hero gets 2px extra to feel proportionally consistent at larger size
- Hero card inner padding: 24px (lg) — more breathing room than secondary 16px

Source: CONTEXT.md locked grid decisions + `index.css` `--space-*` tokens.

## Typography

All TV components use `Space Mono, monospace`. This is the locked font for the TV route. Rajdhani and Outfit are NOT used on the TV dashboard.

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| TV hero value | 48px | 700 (bold) | 1.1 | Space Mono | Primary sensor value in hero card |
| TV secondary value | 28px | 700 (bold) | 1.1 | Space Mono | Primary sensor value in secondary cards |
| TV meta / status bar | 16px | 400 (regular) | 1.0 | Space Mono | StatusBar text, sol counter, all StatusBar content |
| TV label / badge | 12px | 400 (regular) | 1.4 | Space Mono | Sensor name label, zone abbreviation, zone status badge |

Letter spacing: `0.08em` for labels and status text; `0.1em` for sol counter. This matches HabitatHUD existing patterns.

Two weights only: **regular (400)** and **bold (700)**. No semibold.

Notes on consolidation:
- Sol counter uses 16px (same as all StatusBar text). At TV viewing distance the one-step difference from 18px is imperceptible and adds zero hierarchy value.
- Zone status badge uses 12px bold (consolidated from 11px). Badge weight is 700 to distinguish from sensor label weight 400 at the same size.

Source: CONTEXT.md locked decisions (48px+ primary per DATA-01, 24px+ labels) + HabitatHUD.tsx pattern (`fontSize: '1.5rem'`, `fontWeight: 'bold'`).

## Color

All colors from `index.css` `:root` tokens and STATUS_COLORS in HabitatHUD.

| Role | Value | Token | Usage |
|------|-------|-------|-------|
| Dominant (60%) | `#06070b` | `--bg-void` | Full viewport background, StatusBar background (transparent inherits this) |
| Secondary (30%) | `#0c0e16` | `--bg-surface` | Zone card backgrounds |
| Accent green (10%) | `#00ff88` | `--accent-green` | Nominal status dot, nominal status text, ALL SYSTEMS NOMINAL message |

Accent reserved for: status dot when zone is nominal, StatusBar alert text when all systems nominal, sparkline line color when sensor is green-status.

Semantic status colors (not accent — carry meaning):

| Status | Border / Glow | Dot | Text | Token / Source |
|--------|--------------|-----|------|----------------|
| Nominal (green) | `rgba(255,255,255,0.06)` | `#00ff88` | `#00ff88` | `--accent-green` |
| Caution (yellow) | `rgba(255,170,0,0.4)` | `#ffaa00` | `#ffaa00` | `--accent-yellow` |
| Critical (red) | pulsing glow (see below) | `#ff2200` | `#ff2200` | locked hex from CONTEXT.md |

Muted text for non-status content: `#9ca3af` (StatusBar secondary text, sensor labels). This matches HabitatHUD `rgba(156,163,175,1)`.

Destructive: `--accent-red` (`#ff2244` from index.css). Note: critical zone pulse uses `#ff2200` (slightly different — orange-red vs pink-red). Use `#ff2200` for all TV CRITICAL indicators to match STATUS_COLORS in HabitatHUD. Reserve `#ff2244` for non-TV destructive actions only.

Source: CONTEXT.md zone border states + STATUS_COLORS in HabitatHUD.tsx + `index.css` tokens.

## Component Visual Specifications

### StatusBar

```
[• STATUS MESSAGE          ]  [ SOL 000 ]  [ • Data Source   ]
  ←— flex: 1, left          ←— center     ←— flex: 1, right →
```

- Container: `height: 48px`, `display: flex`, `alignItems: center`, `padding: 0 32px`
- Background: transparent (inherits `#06070b` from TvDashboardView)
- No borders, no separators, no animation
- Status dot: 8px circle with `boxShadow: 0 0 6px {statusColor}`
- Status message font: 16px Space Mono, color = `#9ca3af` (nominal) or status color (caution/critical)
- Sol counter font: 16px Space Mono, color white (`#e2e5ed`), `letterSpacing: 0.1em`
- Connection source: inline from BADGE_CONFIG — dot (6px) + label text, no pulse animation (bar has zero animation per locked decision)

### ZoneCard

```
┌─────────────────────────────────────────────┐  ← border (status-reactive)
│  ZONE NAME                    • NOMINAL     │  ← header row
│                                              │
│  Sensor Name      12.4 pH     [sparkline]  │  ← sensor row (per sensor)
│  Sensor Name      23.1 °C     [sparkline]  │
│  ...                                         │
└─────────────────────────────────────────────┘
```

- Border radius: 10px (secondary), 12px (hero)
- Background: `#0c0e16` (`--bg-surface`) — solid, no glassmorphism per REQUIREMENTS.md out-of-scope
- Border: status-reactive (see Color section above)
- Hero card: `gridColumn: 1 / -1`, inner padding 24px, value text 48px bold
- Secondary cards: inner padding 16px, value text 28px bold
- Zone name: 12px Space Mono, `#9ca3af`, `letterSpacing: 0.08em`, uppercase
- Zone status badge (top-right): 12px bold Space Mono, status color text, status dot 6px preceding label
- Sensor row layout: `display: flex`, `alignItems: center`, `justifyContent: space-between`; sensor name left, value center, sparkline right
- Sensor name: 12px Space Mono, `#9ca3af`
- Sensor value: hero = 48px bold, secondary = 28px bold, color = sensor status color
- Unit suffix: displayed inline with value, same size but weight 400 (regular)
- Sparkline: hero = 200×40px, secondary = 120×30px; line color = sensor status color

### Critical Pulse Animation (STAT-02)

Keyframe name: `zoneCriticalPulse`
Cycle: 2s, `ease-in-out`, `infinite`
Resting state: `border: 1px solid rgba(255,34,0,0.3)`, no box-shadow
Peak state (50%): `border: 1px solid #ff2200`, `box-shadow: 0 0 20px rgba(255,34,0,0.4)`
Injection: single DOM `<style id="tv-zone-animations">` tag, ID-guarded

### PriorityGrid

```
┌────────────────────────────────────────────────────────┐ ← 32px padding
│  ┌────────────────────────────────────────────────┐    │
│  │                  HERO ZONE CARD                │    │  55fr row
│  └────────────────────────────────────────────────┘    │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  │
│  │  SECONDARY   │  │  SECONDARY   │  │  SECONDARY   │  │  45fr row
│  └──────────────┘  └──────────────┘  └──────────────┘  │
└────────────────────────────────────────────────────────┘
         ↑ 24px gap between all cards
```

- `display: grid`, `gridTemplateColumns: 1fr 1fr 1fr`, `gridTemplateRows: 55fr 45fr`
- `gap: 24px`, `padding: 32px`, `height: 100%`, `boxSizing: border-box`
- Hero: `gridColumn: 1 / -1`, `gridRow: 1`
- Secondary: `gridRow: 2` (auto-placed left to right in columns 1, 2, 3)

## Copywriting Contract

This is a non-interactive TV display. There are no CTAs, no form submissions, no modals. Copywriting applies to data states and status messages only.

| Element | Copy |
|---------|------|
| Primary CTA | none — TV display, zero interaction |
| StatusBar nominal | `ALL SYSTEMS NOMINAL` |
| StatusBar caution (single zone) | `{ZONE FULL NAME}: CAUTION` (e.g. `WATER RECYCLING: CAUTION`) |
| StatusBar critical (single zone) | `{ZONE FULL NAME}: CRITICAL` (e.g. `ATMOSPHERE CONTROL: CRITICAL`) |
| StatusBar worst-of-many | Show worst zone only — one message at a time |
| Zone status badge nominal | `NOMINAL` |
| Zone status badge caution | `CAUTION` |
| Zone status badge critical | `CRITICAL` |
| Sol counter format | `SOL 000` (zero-padded to 3 digits) |
| Connection badge — biosim | `BioSim Live` |
| Connection badge — biosim-real | `BioSim + Real Sensor` |
| Connection badge — connecting | `Connecting...` |
| Connection badge — disconnected | `Disconnected` |
| Connection badge — fallback | `Fallback Mode` |
| Empty / initial state | No special state — `buildInitialZones()` initializes all zones green; grid renders immediately |
| Error state | Not applicable — TV display has no error UI; data falls back to last known values |
| Destructive confirmation | None — no destructive actions in this phase |

Zone full names (for StatusBar alert messages):

| Zone ID | Full Name (uppercase in StatusBar) |

## Interaction Contract

This phase has zero interactive elements. The TV dashboard is non-interactive by requirement (LAYOUT-01, completed Phase 17). The following interactions are explicitly forbidden:

- No hover states on any element
- No click handlers
- No focus states
- No touch targets
- No tooltips
- No cursor changes

The only "interaction" is the passive CSS animation on red-status zone card borders (STAT-02). This is ambient, not triggered by user input.
