    3. **Main function `biosim_tick_to_rows(modules: dict, tick_time=None) -> list[EnrichedSensorData]`:**
       - If `tick_time is None`: use `timezone.now()`
       - Initialize empty `rows = []`
       - Use Python's `.get()` chains for safe nested access (equivalent to TS optional chaining)

       **Extraction logic (same conversions as TypeScript mapper):**

       GROW BAYS:
       - gb-temp: `modules.get('Crew_Quarters_Environment', {}).get('properties', {}).get('temperature')` (direct C)
         sensor_name = 'temperature'
       - gb-humidity: `.get('relativeHumidity')` (direct %)
         sensor_name = 'humidity'
       - gb-co2: `modules.get('Co2GasConcentrationSensor', {}).get('properties', {}).get('value')` then `* 1_000_000`
         sensor_name = 'co2'
         // CO2: mol fraction * 1e6 = ppm (0.00073 -> 730 ppm)

       ATMOSPHERE CONTROL:
       - ac-o2: `modules.get('O22GasConcentrationSensor', {}).get('properties', {}).get('value')` then `* 100`
         sensor_name = 'o2'
         // O2: mol fraction * 100 = % (0.20807 -> 20.81%)
       - ac-pressure: `.get('totalPressure')` (direct kPa)
         sensor_name = 'pressure'
       - ac-filtration: Find VCCR Air consumer and producer by type string:
         ```python
         vccr = modules.get('VCCR', {})
         air_consumer = next((c for c in vccr.get('consumers', []) if c.get('type') == 'Air'), None)
         air_producer = next((p for p in vccr.get('producers', []) if p.get('type') == 'Air'), None)
         if air_consumer and air_producer:
             in_flow = air_consumer.get('rates', {}).get('actualFlowRates', [None])[0]
             out_flow = air_producer.get('rates', {}).get('actualFlowRates', [None])[0]
             if in_flow and out_flow and in_flow > 0:
                 filtration = (out_flow / in_flow) * 100
         ```
         sensor_name = 'filtration'
         // VCCR filtration: air output / air input * 100 = % efficiency

       WATER RECYCLING:
       - wr-flow: Find `Crew_Quarters_Group` consumer with type `PotableWater`:
         ```python
         crew = modules.get('Crew_Quarters_Group', {})
         potable = next((c for c in crew.get('consumers', []) if c.get('type') == 'PotableWater'), None)
         if potable:
             flow_rate = potable.get('rates', {}).get('actualFlowRates', [None])[0]
             if flow_rate is not None:
                 wr_flow = flow_rate * 60  # L/tick * 60 = L/min
         ```
         sensor_name = 'flow'
         // Potable water: L/tick * 60 = L/min (tick = 1s)
       - wr-ph: `grey_level / grey_capacity * 1.5 + 6.0`
         sensor_name = 'ph'
         // Grey water fill ratio -> pH proxy
       - wr-tds: `dirty_level / dirty_capacity * 10000`
         sensor_name = 'tds'
         // Dirty water fill ratio * 10000 = ppm TDS proxy

       POWER & THERMAL:
       - pt-power: Find `Nuclear_Source` producer with type `Power`, then `flow / 30`
         sensor_name = 'power'
         // Nuclear power: BioSim watts / 30 -> kW (3000 W = 100 kW nominal)
       - pt-battery: `level / capacity * 100`
         sensor_name = 'battery'
         // Power store: level / capacity * 100 = % charge
       - pt-coolant: `temperature + 1.0`
         sensor_name = 'coolant'
         // Crew quarters temp + 1C coolant offset proxy
