def discover_sim_id(biosim_url):
    resp = requests.get(f"{biosim_url}/api/simulation")
    resp.raise_for_status()
    data = resp.json()
    if isinstance(data, list):
        simulations = data
    else:
        simulations = data.get("simulations", [])
    if not simulations:
        raise CommandError("No active simulation found on BioSim server.")
    return simulations[0]

    **Command class:**

    ```python
    class Command(BaseCommand):
        help = "Closed-loop pH control: monitors Pi vs BioSim pH divergence and triggers Grey_Water_Store malfunctions"

        def handle(self, *args, **options):
            self.stdout.write(f"[control_loop] Starting -- BIOSIM_URL={BIOSIM_URL}, PH_THRESHOLD={PH_THRESHOLD}, STALE_SECONDS={STALE_SECONDS}")
            self.stdout.write(f"[control_loop] Querying Pi: hub_id={PI_HUB_ID}, sensor_id={PI_SENSOR_ID}")
            self.stdout.write(f"[control_loop] Querying BioSim: hub_id={BIOSIM_HUB_ID}, sensor_id={BIOSIM_SENSOR_ID}")

            sim_id = self._probe_with_retry()

            malfunction_active = False
            malfunction_id = None
            was_stale = False
            loop_count = 0

            while True:
                loop_count += 1
                malfunction_active, malfunction_id, was_stale = self._run_cycle(
                    sim_id, loop_count, malfunction_active, malfunction_id, was_stale
                )
                time.sleep(POLL_INTERVAL)
    ```

    **_probe_with_retry(self):**
    - Exponential backoff delays: `[2, 4, 8, 16, 30]`
    - Loop: call `probe_sim_id(BIOSIM_URL)`, if result is not None log and return it
    - On exception or None: log retry message with delay, sleep, increment attempt

    **_run_cycle(self, sim_id, loop_count, malfunction_active, malfunction_id, was_stale):**
    This is the core state machine. Must return `(malfunction_active, malfunction_id, was_stale)`.

    1. `pi_row = get_latest(PI_HUB_ID, PI_SENSOR_ID)`
    2. Check staleness: `if is_stale(pi_row, STALE_SECONDS):`
       - If `not was_stale`: log `"[control_loop] Pi data went stale -- holding malfunction state"`
       - Return `(malfunction_active, malfunction_id, True)` -- no state changes
    3. If `was_stale` was True: log `"[control_loop] Pi data resumed -- Pi pH={pi_row.sensor_val:.2f}"`
    4. `biosim_row = get_latest(BIOSIM_HUB_ID, BIOSIM_SENSOR_ID)`
       - If biosim_row is None: return unchanged (can't compute divergence)
    5. `divergence = abs(pi_row.sensor_val - biosim_row.sensor_val)`
    6. `recovery_threshold = PH_THRESHOLD - 0.1` (hysteresis deadband per user decision)
    7. If `not malfunction_active and divergence >= PH_THRESHOLD`:
       - `try:` `malfunction_id = post_malfunction(BIOSIM_URL, sim_id)` + set `malfunction_active = True`
       - Log: `"[control_loop] MALFUNCTION triggered -- divergence={divergence:.2f} (Pi pH={pi_row.sensor_val:.2f}, BioSim pH={biosim_row.sensor_val:.2f})"`
       - `except requests.RequestException as e:` log `"[control_loop] BioSim POST failed ({e}) -- skipping cycle"`
    8. Elif `malfunction_active and divergence < recovery_threshold`:
       - `try:` `delete_malfunction(BIOSIM_URL, sim_id, malfunction_id)` + set `malfunction_active = False`, `malfunction_id = None`
       - Log: `"[control_loop] MALFUNCTION cleared -- divergence={divergence:.2f} (Pi pH={pi_row.sensor_val:.2f}, BioSim pH={biosim_row.sensor_val:.2f})"`
       - `except requests.RequestException as e:` log `"[control_loop] BioSim DELETE failed ({e}) -- skipping cycle"`
    9. Heartbeat: `if loop_count % HEARTBEAT_INTERVAL == 0:`
       - `state = 'malfunction' if malfunction_active else ('stale' if is_stale(pi_row, STALE_SECONDS) else 'normal')`
       - Log: `"[control_loop] alive -- Pi pH={pi_row.sensor_val:.2f}, BioSim pH={biosim_row.sensor_val:.2f}, divergence={divergence:.2f}, state={state}"`
    10. Return `(malfunction_active, malfunction_id, False)`
