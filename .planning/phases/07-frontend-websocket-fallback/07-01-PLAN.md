    This is a module Worker file (runs in Worker global scope, not DOM scope).

    Import `mapBioSimToHabitatReadings` from `'../simulation/biosimMapper'` (ESM import works because Worker is instantiated with `{ type: 'module' }`).
    Import `WorkerCommand` and `WorkerMessage` types from `'../types/habitat'`.

    Module-level state:
    - `let ws: WebSocket | null = null;`
    - `let existingHistory: Record<string, Record<string, number[]>> = {};`

    Message handler (`self.onmessage`):
    - On `CONNECT`: call `connect(wsUrl)` -- close any existing WS first, then open new one
    - On `DISCONNECT`: call `disconnect()` -- close WS, null it out
    - On `SYNC_HISTORY`: update `existingHistory` from the provided history object (used when switching from sim engine to BioSim -- preserves sparkline continuity per user decision)

    `connect(wsUrl: string)`:
    - Close existing WS if any (`ws?.close()`)
    - `ws = new WebSocket(wsUrl)`
    - `ws.onopen`: post `{ type: 'WS_OPEN' }` to main thread
    - `ws.onclose`: post `{ type: 'WS_CLOSE', code: e.code }` to main thread
    - `ws.onerror`: post `{ type: 'WS_ERROR' }` to main thread
    - `ws.onmessage`: parse `e.data` as JSON, extract `payload.modules`, call `mapBioSimToHabitatReadings(payload.modules, Date.now(), existingHistory)`, then update `existingHistory` from the returned readings (extract `.history` arrays), then post `{ type: 'READINGS', readings }` to main thread
    - Wrap JSON.parse in try/catch -- on parse error, log to console but do NOT crash the Worker

    `disconnect()`:
    - `ws?.close()`
    - `ws = null`
    - Do NOT clear existingHistory (preserved for reconnection sparkline continuity)

    **1. Create `src/hooks/useSimSource.ts`:**

    This is the single orchestration hook that HabitatView will call. It manages the full lifecycle:

    **Exports:** `export function useSimSource(): void` (no return value -- all state goes through habitatStore).

    **Configuration constants (top of file, exported for testing):**
    - `export const BIOSIM_BASE_URL = import.meta.env.VITE_BIOSIM_URL ?? 'http://localhost:8009'`
    - `export const PROBE_INTERVAL_MS = 15_000` (background probe every 15s)
    - `export const PROBE_TIMEOUT_MS = 5_000` (HTTP probe timeout)
    - `export const RETRY_DELAYS = [1000, 2000, 4000]` (exponential backoff, 3 attempts)
    - `export const DISCONNECTED_DISPLAY_MS = 2000` (show "Disconnected" badge for 2s before fallback)

    **Probe function (module-level, exported for testing):**
    `export async function probeBioSim(): Promise<string | null>`
    - `fetch(\`${BIOSIM_BASE_URL}/api/simulation\`, { signal: AbortController.timeout(PROBE_TIMEOUT_MS) })`
    - On success: parse response JSON, expect array, take first element, extract simID
    - Handle both `[1]` (numeric array) and `[{ id: 1 }]` (object array) formats
    - On any error (network, timeout, parse): return null
    - Return simID as string, or null if BioSim unavailable

    **WS URL derivation (module-level, exported for testing):**
    `export function wsUrl(simId: string): string`
    - Replace `http` with `ws` in BIOSIM_BASE_URL, append `/ws/simulation/${simId}`
    - Handle both `http://` and `https://` -> `ws://` and `wss://`

    **Hook body:**

    Refs (useRef):
    - `workerRef: Worker | null` -- the Web Worker instance
    - `pendingReadings: Record<string, Record<string, SensorReading>> | null` -- RAF buffer
    - `rafHandle: number | null` -- requestAnimationFrame handle
    - `probeTimerRef: ReturnType<typeof setInterval> | null` -- background probe timer
    - `retryCountRef: number` -- current retry attempt (0-2)
    - `retryTimerRef: ReturnType<typeof setTimeout> | null` -- retry delay timer
    - `disconnectedTimerRef: ReturnType<typeof setTimeout> | null` -- 2s disconnected display timer
    - `mountedRef: boolean` -- guard against post-unmount state updates

    **Single useEffect with [] deps (the entire lifecycle):**

    On mount:
    1. `mountedRef.current = true`
    2. Set `simSource` to `'connecting'`
    3. Start client-side simulation engine immediately (zero blank-screen time per user decision):
       `useHabitatStore.getState().startSimulation()`
    4. Create Worker: `new Worker(new URL('../workers/biosimWorker.ts', import.meta.url), { type: 'module' })`
    5. Set up Worker.onmessage handler:
       - `WS_OPEN`: Stop sim engine (`useHabitatStore.getState().stopSimulation()`), set simSource to `'biosim'`, reset retryCount to 0, start RAF loop
       - `READINGS`: Store in `pendingReadings.current` (last-value-wins on burst)
       - `WS_CLOSE`: Handle disconnection (see reconnection logic below)
       - `WS_ERROR`: (no-op -- WS_CLOSE always follows WS_ERROR)
    6. Probe BioSim: call `probeBioSim()`
       - If simID found: extract current sparkline history from store zones (build existingHistory record), send `SYNC_HISTORY` to Worker, then send `CONNECT` with `wsUrl(simID)` to Worker
       - If null: keep sim engine running, set simSource to `'fallback'`, start background probe timer
    7. Start background probe timer (`setInterval` at PROBE_INTERVAL_MS):
       - Only acts when simSource is `'fallback'` (skip if already connected or connecting)
       - Call `probeBioSim()`, if simID found:
         - Set simSource to `'connecting'`
         - Extract existingHistory from store, send `SYNC_HISTORY` then `CONNECT` to Worker

    **Reconnection logic (on WS_CLOSE):**
    - If `!mountedRef.current`: do nothing (component unmounted)
    - Set simSource to `'disconnected'`
    - If `retryCountRef.current < RETRY_DELAYS.length`:
      - Schedule retry after `RETRY_DELAYS[retryCountRef.current]` ms
      - On retry: re-probe BioSim (fresh simID per Pitfall 2 -- handles BioSim restart). If simID found, send CONNECT. If null, increment retry count, schedule next retry or fall through to fallback.
      - Increment retryCountRef
    - If retries exhausted:
      - After DISCONNECTED_DISPLAY_MS (2s), set simSource to `'fallback'`, start sim engine

    **RAF loop functions:**
    `startRAFLoop()`: Start requestAnimationFrame loop that checks `pendingReadings.current`, calls `useHabitatStore.getState().tick(readings)` if non-null, then nulls it out. Schedule next frame.
    `stopRAFLoop()`: cancelAnimationFrame, null out rafHandle.

    **Extract history helper:**
    `function extractHistory(): Record<string, Record<string, number[]>>` -- reads current store zones and builds the existingHistory record for SYNC_HISTORY command.

    **Cleanup (useEffect return):**
    1. `mountedRef.current = false`
    2. Stop RAF loop
    3. Send DISCONNECT to Worker, then `worker.terminate()`
    4. Clear probe timer (`clearInterval`)
    5. Clear retry timer (`clearTimeout`)
    6. Clear disconnected display timer (`clearTimeout`)
    7. Stop sim engine: `useHabitatStore.getState().stopSimulation()`
    8. Null out all refs

    **Critical invariants:**
    - FALL-04: Exactly one source at a time. When switching to BioSim (WS_OPEN), always stop engine first. When switching to fallback, always stop RAF loop first.
    - PERF-02: Never call `useHabitatStore()` (the hook) inside useSimSource -- always use `useHabitatStore.getState()` for imperative access. The hook is not subscribing to store changes.
    - Navigation: Navigate-away-and-back 5 times = exactly 1 WS connection. The useEffect cleanup guarantees this.
