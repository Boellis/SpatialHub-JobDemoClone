Extend the existing deploy.sh with new sections AFTER the current Section 8 (smoke checks) but BEFORE the final summary. Renumber the final summary section accordingly. Add these new sections:

**New VM constants** (add to the Constants section at the top):
```bash
VM_NAME="spatialhub-biosim"
STATIC_IP_NAME="spatialhub-biosim-ip"
ZONE="us-central1-a"
BIOSIM_TAG="biosim-server"
```

**Section 9: Reserve Static IP (idempotent)**
- Check if static IP exists: `gcloud compute addresses describe "$STATIC_IP_NAME" --region="$REGION" --project="$PROJECT"`
- If not: `gcloud compute addresses create "$STATIC_IP_NAME" --region="$REGION" --project="$PROJECT"`
- Fetch the IP: `gcloud compute addresses describe ... --format='value(address)'` into `$VM_IP`
- Print the IP

**Section 10: Create Firewall Rules (idempotent)**
- Two rules: `allow-biosim-8009` (tcp:8009) and `allow-openmct-9091` (tcp:9091)
- Both use `--target-tags "$BIOSIM_TAG"` and `--source-ranges 0.0.0.0/0`
- Check existence before creating (same pattern as Cloud SQL section)

**Section 11: Create GCE VM (idempotent)**
- Check if VM exists: `gcloud compute instances describe "$VM_NAME" --zone="$ZONE" --project="$PROJECT"`
- If not: create with `--machine-type=e2-medium --image-family=debian-12 --image-project=debian-cloud --address="$STATIC_IP_NAME" --tags="$BIOSIM_TAG" --boot-disk-size=20GB`
- After creation, `sleep 30` to allow SSH key propagation (per Research pitfall 6)

**Section 12: Install Docker on VM (idempotent)**
- SSH into VM and check if docker is installed: `gcloud compute ssh "$VM_NAME" --zone="$ZONE" --project="$PROJECT" --quiet --command="command -v docker"`
- If not installed: SSH and run `sudo apt-get update && sudo apt-get install -y docker.io docker-compose-plugin git curl && sudo usermod -aG docker \$USER`
- Use `--quiet` on all gcloud compute ssh commands

**Section 13: Deploy Code to VM**
- SSH: If `/opt/spatialhub` does not exist, `sudo mkdir -p /opt/spatialhub && sudo chown \$USER:\$USER /opt/spatialhub && git clone {REPO_URL} /opt/spatialhub` (use the GitHub HTTPS URL for this repo). If it exists, `cd /opt/spatialhub && git pull origin main`.
- NOTE: The repo URL should be derived or hardcoded. Use `git remote get-url origin` locally to get it, store in a variable.
- SSH: Write .env file to `/opt/spatialhub/.env` with DB_HOST, DB_NAME, DB_USER, DB_PASS, SECRET_KEY values from the deploy script's environment.
- SSH: Write systemd unit file to `/etc/systemd/system/spatialhub-biosim.service` using `sudo tee`. Unit file:
  - `[Unit]` Requires=docker.service, After=docker.service network-online.target
  - `[Service]` Type=oneshot, RemainAfterExit=yes, WorkingDirectory=/opt/spatialhub
  - ExecStart=/usr/bin/docker compose -f /opt/spatialhub/docker-compose.vm.yml up -d
  - ExecStop=/usr/bin/docker compose -f /opt/spatialhub/docker-compose.vm.yml down
  - `[Install]` WantedBy=multi-user.target
- SSH: `sudo systemctl daemon-reload && sudo systemctl enable spatialhub-biosim.service`
- SSH: `cd /opt/spatialhub && docker compose -f docker-compose.vm.yml up --build -d`
  - IMPORTANT: Do NOT set a short timeout on this SSH command. First build takes 10-20 minutes for BioSim Maven download. Use `--ssh-flag="-o ServerAliveInterval=60"` to keep connection alive.

**Section 14: Wait for BioSim Readiness**
- Poll `curl -sf "http://${VM_IP}:8009/api/simulation"` every 3 seconds, up to 40 attempts (120s).
- Print progress on each attempt.
- Exit 1 if BioSim does not respond after 120s.

**Section 15: Rebuild Frontend with VM URLs**
- `cd "$REPO_ROOT/spatialhub-frontend"`
- Build with three env vars: `VITE_API_URL="${CLOUD_RUN_URL}/api" VITE_BIOSIM_URL="http://${VM_IP}:8009" VITE_OPENMCT_URL="http://${VM_IP}:9091" npm run build`
- `firebase deploy --only hosting --project "$PROJECT"`

**Section 16: VM Smoke Checks**
- Check BioSim: `curl -sf "http://${VM_IP}:8009/api/simulation"` (expect 200)
- Check Open MCT: `curl -sf "http://${VM_IP}:9091"` (expect 200)
- Check bridge writes (wait 15s for first tick, then): `curl -s "${CLOUD_RUN_URL}/api/enriched/?hub_id=biosim-habitat-01"` and check response is not empty array
- Print PASS/WARN for each

**Update final summary** to include VM IP, BioSim URL, Open MCT URL.

IMPORTANT implementation notes:
- All `gcloud compute ssh` commands use `--quiet` flag to suppress interactive prompts.
- Use `--ssh-flag="-o ServerAliveInterval=60"` on the docker compose build SSH command to prevent timeout.
- Docker commands on the VM need `sudo` for the first session (before newgrp takes effect). Use `sudo docker compose ...` in the SSH commands to be safe.
- The deploy script's `set -euo pipefail` means any gcloud failure will abort -- this is correct behavior.
