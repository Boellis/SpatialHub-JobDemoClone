Verification steps:

1. **Run the deployment** (first time takes 15-25 min due to BioSim Maven build):
   ```bash
   DB_PASS="your-password" SECRET_KEY="your-key" ./deploy/deploy.sh
   ```
   The script will print progress through all sections including VM provisioning and BioSim readiness poll. Watch for PASS/WARN on each smoke check at the end.

2. **Verify BioSim REST API** -- Visit `http://{VM_IP}:8009/api/simulation` in browser. Should return a JSON array with at least one simulation ID (e.g., `[1]`).

3. **Verify Open MCT** -- Visit `http://{VM_IP}:9091` in browser. Should show the Open MCT telemetry dashboard interface.

4. **Verify 3D Habitat with live BioSim data** -- Visit `https://nasa-comp-demo.web.app/habitat` in browser:
   - ConnectionBadge should show "BioSim Connected" (green) within ~5 seconds
   - Sensor orbs in the 3D habitat should show live updating values from BioSim physics
   - Zone panels should display live sensor readings when clicking a dome

5. **Verify bridge writes to Cloud SQL** -- Run:
   ```bash
   curl -s "https://spatialhub-backend-4vovlomqfa-uc.a.run.app/api/enriched/?hub_id=biosim-habitat-01" | python3 -c "import sys,json; data=json.load(sys.stdin); print(f'{len(data)} rows from biosim bridge')"
   ```
   Should return > 0 rows after 30+ seconds of bridge operation.

6. **Verify AnomalyDrawer** -- On the habitat page, open the Anomaly Drawer and trigger "Pump Failure". The Water Recycling zone should react (zone turns red/yellow within 30s). Cancel the anomaly and verify recovery.

7. **Verify Open MCT nav link** -- From the main SpatialHub nav bar on any non-habitat page, click "Open MCT". It should open `http://{VM_IP}:9091` in a new tab (NOT localhost:9091).
