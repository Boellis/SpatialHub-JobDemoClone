    In `useSimSource.ts`, the simId is discovered in the probe but only used to build the WebSocket URL. It needs to be stored so the WS_OPEN handler can call `setBiosimSimId`.

    Add a `simIdRef = useRef<string | null>(null)` to the hook. Set it whenever a simId is discovered from `probeBioSim()`.

    There are 3 probe sites in `useSimSource.ts` that discover a `simId`:
    1. **Initial probe** (line ~251): `probeBioSim().then((simId) => { ... })` -- add `simIdRef.current = simId;` when simId is non-null.
    2. **Retry probe** (line ~180): `const simId = await probeBioSim();` -- add `simIdRef.current = simId;` when simId is non-null.
    3. **Background probe** (line ~237): `const simId = await probeBioSim();` -- add `simIdRef.current = simId;` when simId is non-null.

    **Step 2: Set biosimSimId on WS_OPEN**

    In the `WS_OPEN` case of `worker.onmessage`, add after `setSimSource('biosim')`:
    ```typescript

      useHabitatStore.getState().setBiosimSimId(simIdRef.current);
    }
    ```
